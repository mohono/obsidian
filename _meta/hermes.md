# راهنمای Hermes برای مدیریت کار

## Timezone
همه‌ی تاریخ‌ها و «امروز/فردا» بر اساس Asia/Tehran حساب می‌شن.

## ساختار Vault
- 00-Inbox/inbox.md   → ثبت سریع، فقط به آخرش اضافه کن (append-only)، هیچ‌وقت خطوط قبلی رو دست نزن
- 10-Tasks/tasks.md   → تسک‌های اصلی و دارای سررسید
- 20-Daily/YYYY-MM-DD.md → یادداشت روزانه
- 30-Weekly/YYYY-Www.md  → مرور هفتگی

## فرمت تسک (استاندارد پلاگین Tasks)
هر تسک یک خط چک‌باکس markdown:
- [ ] متن تسک 📅 YYYY-MM-DD 🔼 🔁 every week
وضعیت‌ها:
- [ ] انجام‌نشده
- [/] در حال انجام
- [x] انجام‌شده  ✅ YYYY-MM-DD  (تاریخ اتمام رو اضافه کن)
- [-] کنسل‌شده
نمادها:
- 📅 = تاریخ سررسید (اجباری برای تسک دارای موعد)
- ⏳ = تاریخ شروع/برنامه‌ریزی
- 🔼 مهم / 🔽 کم‌اهمیت
- 🔁 = تکرار، مثلا: 🔁 every day / 🔁 every week / 🔁 every month

## قوانین رفتاری
- وقتی تسک جدید می‌گیرم، اگه تاریخ مشخص نکردی و از متن هم درنیومد، ازم بپرس برای چه روزی.
- تسک‌های دارای موعد رو توی 10-Tasks/tasks.md بنویس.
- ثبت‌های سریع و بی‌تاریخ رو به 00-Inbox/inbox.md اضافه کن.
- بعد از هر تغییر، طبق قانون vault-git پوش کن.
- تأییدها رو کوتاه بده.
